# 开发目标与进度跟踪计划 (Development Plan)

本文档跟踪项目从零构建到成熟上线的全生命周期任务列表，各模块按里程碑划分，确保按部就班高效落地。

---

## 一、 开发总目标

构建一套**高度自治、低边际成本、零版权纠纷**的 AI 商业带货短视频系统。
* **输入**：商品实拍图 1~3 张 + 核心卖点 / 痛点简述
* **核心产出**：30 秒左右竖屏 9:16 高清带货短视频（包含角色动作、环境音、自然口语配音、高亮逐字字幕、AIGC 标识）
* **效率指标**：单条成片总生成与渲染时长控制在 **3~5 分钟内**，成本逼近 **¥0**。

### 阶段 1：本地基础后端与合规音频流水线 (T4 闭环)
> **目标**：在本地不调用任何外部付费服务的情况下，打通文本输入到音频生成与时间戳对齐。

- [ ] **初始化本地工程骨架**：
  - 构建 Python FastAPI（或 Node.js）后端骨架与 SQLite 数据表。
- [ ] **部署本地 CosyVoice 2 (TTS)**：
  - 在 Tesla T4 上加载 CosyVoice 2 (0.5B) 模型；
  - 封装 `/api/tts/synthesize` 接口，输出 `.wav` 文件。
- [ ] **集成 Faster-Whisper (ASR)**：
  - 加载 Faster-Whisper Large-v3 模型；
  - 抽取音频中的单字/词级时间戳（毫秒级对齐），生成 ASS / 字幕卡数据结构。
- [ ] **FFmpeg 硬件音频合成与 Voice Grounding 验证**：
  - 编写手机麦克风 EQ 模拟滤镜（90Hz 高通 + 9500Hz 低通 + 3:1 动态压缩）；
  - 混入微弱布朗环境底噪，验证音频“消除数码死寂”效果。

---

### 阶段 2：大脑接入与脚本五判官机制 (Gemini 2.0)
> **目标**：输入商品图，直接输出结构化、符合广告法且经过 5 位判官审查的优质电商分镜。

- [ ] **Gemini 多模态卖点提炼**：
  - 调用 Gemini 2.0 Flash 视觉能力，识别上传商品实拍图的品类、外观特征与使用场景。
- [ ] **结构化分镜生成 Prompt 引擎**：
  - 输出固定 JSON 格式：包含 4~6 个分镜（镜头类型：钩子/痛点/商品/演示/背书/转化，预估秒数，视觉动作，配音台词）。
- [ ] **五判官质检与等长重写系统**：
  - 节奏官（Pace）：查前 3 秒钩子强度；
  - 口语官（Voice）：剔除播音腔，重写为真实对话；
  - 画面官（Visual）：将“展示产品”重写为可见具体动作；
  - 等长校验：计算重写前后字数，防止 TTS 音频超出分镜预定时长；
  - 广告法违禁词自动拦截与替换。
